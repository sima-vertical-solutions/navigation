# Runtime dependencies of the navigation package that dpkg-shlibdeps cannot
# work out for itself. Merged with the shlibdeps result by
# packaging/build-navigation-deb.sh.
#
# shlibdeps maps a SONAME to a package through the dpkg shlibs database, which
# only covers libraries installed in a system library path, and it reads only
# the DT_NEEDED of the files it is handed. So two categories have to be
# declared here:
#
#   1. anything under /usr/local -- ROS 2 itself, which is where essentially
#      every one of these libraries comes from;
#   2. anything reached transitively rather than directly.
#
# Everything else in the eLxr recipe's rdeps list (libompl16, libfcl0.7,
# libceres3, libgraphicsmagick++-q16-12, the Boost and Qt runtimes, ...) lives
# in a system path and IS linked directly, so shlibdeps finds it with the right
# version constraint. Repeating those here by hand would only let the two lists
# drift.

# --- /usr/local, invisible to shlibdeps ---
ros2

# --- reached through the ROS 2 libraries this tree links, not directly ---
#
# liblttng-ust is the rcl tracepoint provider that every rclcpp node pulls in,
# and yaml-cpp comes in through yaml_cpp_vendor, which nav2_map_server and
# opennav_docking both use. Both live in /usr/local/ros2 and belong to the ros2
# package, which declares liblttng-ust1 itself as of 2.1.3 but still not
# libyaml-cpp0.7. Declaring both keeps this package installable on a stock
# bookworm even if ros2's own declarations change again, which is exactly what
# packaging/smoke-test.sh asserts.
#
# libassimp5 used to be here too. It was reached only through librviz_rendering,
# i.e. only through nav2_rviz_plugins, which is now excised from the build.
liblttng-ust1
libyaml-cpp0.7

# --- python, loaded by name at runtime ---
#
# nav2_simple_commander and the nav2_bringup launch files are Python, and
# nothing in a .so's DT_NEEDED records that. From the eLxr rdeps list plus what
# the launch files import.
python3
python3-numpy
python3-yaml

# --- tracing, from the eLxr rdeps list ---
lttng-tools
